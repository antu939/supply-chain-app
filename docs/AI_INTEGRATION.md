# AI 接入说明（第三阶段完成版）

本文档说明供应链管理软件正式 AI 助手的整体接入架构、配置方式、授权操作流程、留证机制与已知限制。

---

## 一、三阶段整体架构

```text
用户界面（全局 AI 侧边栏 app/ai-sidebar.js）
  ↓ 当前模块 / 选中主体（可见、可清除）+ 有界对话历史
模型编排与适配层（shared/ai-client.js）
  ├─ 脱敏与双出口网关（shared/ai-privacy*.js + shared/ai-anonymizer.js）
  ├─ 6 个只读业务工具（shared/ai-tools.js + ai-tool-handlers.js + ai-tool-registry.js）
  │    └─ 复用 SCAIQuery / SCDataStore / SC.SimEngine / SC.TimeSeries
  ├─ 受控授权写操作（shared/ai-mutations.js）
  │    └─ 复用 SC.Actions.simulateActions / applyActions（7 步校验与持久化）
  └─ 本地独立留证存储（shared/ai-audit.js -> sc-ai-audit-v1）
```

- **默认只读**：不经用户显式限时授权，AI 仅能调用只读工具，无法修改任何正式业务数据。
- **隐私先行**：所有对外模型请求与工具返回均经过第一阶段隐私保护层；联网搜索使用完全独立的 `web_search` 出口策略。
- **不引入外部依赖**：保持纯原生 JavaScript，不引入 Python、向量数据库、复杂 Agent 框架或幕布。

## 二、快速配置与使用方式

1. 按原项目方式启动本地静态服务并打开首页：
   ```bash
   cd supply-chain-app
   python3 -m http.server 8765
   ```
   浏览器访问 `http://127.0.0.1:8765/`。
2. 点击顶部栏右侧 **「AI 助手」** 展开全局侧边栏，点击右上角 **「设置」** 填写模型配置：
   - **API Base URL**：服务商的 OpenAI 兼容接口地址（如 `https://api.deepseek.com/v1` 或其他兼容服务商地址）。
   - **API Key**：个人或企业测试凭据。**仅保存在当前浏览器标签页的 `sessionStorage` 与闭包内存中**，绝不硬编码、不进入模型提示词、不写入业务备份或审计日志；关闭标签页即自动清除。
   - **模型名称**：默认基准占位 `deepseek-v4.1-flash`，实际请以服务商文档公布的模型标识为准。
   - **推理等级（Reasoning Effort）**：默认 `low`（支持 `low` / `medium` / `high` / `none`）。
   - **单次输出 Token 上限 / 单轮工具调用上限 / 流式开关**：默认 `800 tokens`、`6 次工具`、开启流式（若接口返回普通 JSON 会自动回退非流式）。
   - **可选：联网搜索接口 URL**：留空时侧边栏不会向模型暴露联网工具，模型会明确说明未配置联网能力，绝不伪造外部资料。

## 三、只读模式、临时授权写入与运输延期处理

### 1. 临时授权写入
- 默认处于 **「只读模式」**。点击侧边栏顶部状态胶囊可开启 **「临时写入授权」**，需明确选择允许的操作类型与有效期（15 / 30 / 60 分钟），绑定当前工作区，随时可一键撤销。
- 即便处于授权状态，以下高风险行为仍会强制拦截并要求用户在正式业务界面手动处理：
  - 删除/取消记录；
  - 批量修改（一次涉及多条记录）；
  - 改写或覆盖已确认的实际业务事实（`*ActualDate` / `event.record`）；
  - 目标主体不明确或并发数据版本冲突（`VERSION_CONFLICT`）。

### 2. 运输途中延期（区分原始计划 / 最新预计 / 实际事实）
当用户选中在途发运单并下达“当前这批货预计晚到 5 天，帮我调整一下”等指令时：
1. 首次调整 ETA 前自动锁定不可变的 `originalPlan`（保存初始计划天数与计划里程碑）；
2. 仅通过官方 `SC.Actions.simulateActions` 预演并经 `SC.Actions.applyActions` 更新最新预计里程碑（`milestones.*PlannedDate` 与 `revisedEstimate`）；
3. 严禁修改已确认的实际发生日期（如 `departActualDate`）及不可迁移的 `originMonth`、稳定 `id` 与其他无关发运单；
4. 若官方 `SimEngine` 检测到延期导致目标市场首次断货提前或需求缺口扩大，系统会在返回结果与卡片中明确预警，并同步刷新销售界面与总览。

## 四、留证、审计与安全撤销

- **数据分离**：普通聊天记录保存在 `sc-ai-chat-v1`，正式业务修改凭证与决策/研究留证保存在独立的 `sc-ai-audit-v1`。点击侧边栏「清空」仅清除聊天记录，**不会删除正式业务审计凭证**。
- **修改凭证内容**：由系统在正式执行成功后自动生成（不依赖模型撰写），记录唯一凭证号、操作时间、模型标识、用户指令、授权依据、稳定目标 ID、字段前后差异、预演与执行版本号、缺口业务影响，且标记 `localOnly / neverSendToExternalModel`，不会自动回传给外部模型。
- **安全撤销**：在聊天卡片或「留证」面板点击「安全撤销」时，系统会校验当前工作区版本号且确认目标记录未新增已确认实际事实，再通过官方 `SC.Actions` 恢复原计划并生成关联撤销凭证。

## 五、已知限制与联调说明

1. **真实 API 尚未联调**：当前自动化测试使用本地模拟传输层（无真实 API 凭据），填写真实 Base URL 与 API Key 后请先用一条简单只读查询验证目标服务商的字段兼容性（如 `reasoning_effort` 是否被该模型支持）。
2. **浏览器跨域（CORS）限制**：本应用坚持不通过不可信第三方代理转发 API Key；若所选模型服务商禁止浏览器直接跨域请求，建议在桌面端封装（Electron/Tauri）或自建受信任的本地反向代理下调用。
3. **联网搜索依赖外部端点**：本软件内置严格受隐私层门控的搜索适配接口，但默认未绑定外部搜索引擎；需由用户配置可信搜索端点并在需要查询指定企业公开资料时授予独立搜索权限。
4. **模型输出波动**：低成本模型在复杂指令下可能偶尔返回纯文本而非严格 JSON，`ai-client.js` 已内置容错解析，并坚持由本地直接展示官方工具返回的数值与系统生成的修改凭证，不依赖模型复述数值或编造凭证。
