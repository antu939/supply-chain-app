# Sales 供应链业务系统 V0.2 使用说明

本项目位于与 `bom` 同级的独立目录 `supply-chain-sales` 中，定位为**真实日常业务的供应链销售运营与供需规划工作台**（单一正式业务计划，无多情景推演，无中转仓库存模型），**未修改 `bom` 目录内的任何文件**。

## 快速打开

1. 直接在浏览器中双击 `index.html` 即可运行（零构建、无需 Node.js）。
2. 如需与同级 `bom` 共享本机 `localStorage` 数据，可在父目录运行 `python3 -m http.server 8765`，再分别访问 `http://127.0.0.1:8765/supply-chain-sales/` 与 `http://127.0.0.1:8765/bom/`。
3. 也可点击顶部产品标签或「更多 → BOM 产品与工厂资料」，只读导入任意 BOM JSON 备份文件。

## 四个核心页面

1. **总览**：自动定位今天，展示日终可用库存、实际在途、待清关/待上架、已上架次日可售、预计上架、缺货风险市场及待处理异常，支持快速筛选工厂/市场/查看周期，并一键跳转对应发运或市场详情。日终状态、锚点和筛选口径见 [Sales 模拟口径](../../docs/SALES_SIMULATION_STAGE3.md)。
2. **供给与批次**：函数式工厂未来产出曲线编辑器（真实自然日期横轴、平滑拖拽、速率模式与区间总量模式混合、自然日 CSV 导入）及生产批次管理。
3. **物流与清关**：工厂 → 目标市场轻量化运输关系示意地图（一条线汇总该路径下全部发运），下方为可搜索、可筛选的发运单管理列表。每笔发运单独立管理时效、费用、单据、可选停靠港（仅事件记录，不产生库存）与抵港/清关/可售三里程碑；支持复用「常用物流方案」与一键复制发运。
4. **市场与履约**：管理目标市场消费需求曲线、优先级、等待容忍度、可售库存趋势及缺货风险窗口。

## 自动化测试

- 浏览器直接打开 `tests/test-runner.html` 查看测试结果。
- 或终端运行：
  - macOS JavaScriptCore：`/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc -e 'var scriptDir="js"; load("tests/engine.test.js");'`
  - Node.js：`node tests/engine.test.js`

## 最终版按钮入口说明

- **发运创建入口**：通过「供给与批次」的批次列表点击「安排发运」，自动带入批次、工厂、可用日期和剩余数量。「物流与清关」页面不再显示独立的「新建发运」按钮，集中用于发运记录查询、物流方案、CSV 导入和已有发运管理；市场页的「补货发运」仍保留作为带目标市场预填的快捷入口。
- **创建批次**：通常在「供给与批次」页面右上角使用；当产出曲线存在有效框选区间时，顶部按钮暂时隐藏，改用区间内的「生成批次」按钮（自动填入所选日期）。取消框选后恢复顶部按钮。
- 发运复制、批次关联发运及其他业务功能保持不变。
